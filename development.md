## 01. DermAI

**Category**
Artificial Intelligence • Healthcare • Computer Vision

**Status**
Completed

**Overview**

DermAI is an AI-powered skin disease detection platform that assists users and healthcare professionals in identifying skin conditions from medical images. The system performs automated disease classification, generates comprehensive diagnostic reports, stores patient history, and supports early detection through deep learning.

The platform is designed to improve accessibility to preliminary skin analysis while helping medical professionals streamline the diagnostic process.

### Key Features

- AI-powered skin disease classification
- Medical image analysis
- Automated diagnostic reports
- Patient history management
- Prediction confidence scoring
- Responsive web interface
- Fast inference pipeline

### AI Model

- ResNet-50 (Pre-trained)
- Transfer Learning
- Image Classification

### Dataset

- 262,000+ Dermatology Images
- 36 Skin Disease Categories

### Technologies

- Python
- PyTorch
- ResNet-50
- FastAPI
- Next.js
- PostgreSQL
