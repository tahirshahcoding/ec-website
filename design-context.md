# EagleNest Creations - Design Context

## Project Overview

This is NOT a generic agency website.

It is a premium digital experience for EagleNest Creations, a company specializing in:

- AI Development
- Software Development
- Digital Marketing
- Branding
- SEO
- Automation

The website should feel like a premium software product instead of a marketing website.

---

# Inspiration

Take inspiration from:

- Apple
- Linear
- Vercel
- Stripe
- Framer

DO NOT copy any design.

Only take inspiration from their:

- spacing
- typography
- motion
- simplicity
- attention to detail

---

# Overall Feel

The experience should feel:

Elegant

Minimal

Premium

Intelligent

Futuristic

Calm

Interactive

Confident

Never feel:

❌ Cheap

❌ Template based

❌ Over designed

❌ Cartoonish

❌ Full of unnecessary gradients

❌ Full of glassmorphism

❌ Generic SaaS

---

# Theme

Primary theme is Light Mode.

Background should be almost white.

Cards should be white.

Borders should be extremely subtle.

Shadows should be soft.

Whitespace is more important than decoration.

# Motion

Every animation should feel physical.

Use spring animations.

No linear movement.

Buttons

Cards

Images

Icons

Navigation

Everything should animate smoothly.

Never animate just for decoration.

Every animation should improve the experience.

# AI Assistant

The website contains an AI assistant called Eagle AI.

It is part of the experience.

Not a popup.

The AI should help visitors:

- choose services
- answer questions
- recommend solutions
- generate project summaries
- book meetings

---

# Design Rules

Always prefer:

More whitespace

Less decoration

Better typography

Better motion

Cleaner hierarchy

Elegant transitions

Never add random effects.

Never add unnecessary animations.

Never use template-like sections.

Every component should feel handcrafted.

---

# Mobile

Do NOT simply shrink desktop.

Redesign layouts.

Keep interactions touch friendly.

Large tap targets.

Simple navigation.

Maintain the premium experience.

---

# Coding Expectations

Build reusable components.

Use TypeScript.

Use Tailwind CSS.

Use Motion for animations.

Use React Three Fiber only where necessary.

Write clean, scalable code.

---

# Before generating any UI

Always ask yourself:

1. Does this feel premium?

2. Would Apple or Linear ship something with this level of polish?

3. Does it match EagleNest's identity?

If the answer is no,

improve the design before generating code.
